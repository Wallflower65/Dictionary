# 📖 Interactive Dictionary Web App

A comprehensive, responsive dictionary application built to provide users with instant word definitions, phonetic pronunciations, and visual context.

## ✨ Features

* **Real-Time Search:** Fetches accurate definitions, synonyms, and phonetic spelling instantly.
* **Visual Context:** Integrates dynamic image search results related to the queried word.
* **Responsive UI:** Features a clean, custom-designed interface and footer that works seamlessly across all devices.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (ES6+)
* **APIs:** SheCodes API (for definitions and images)
* **Deployment:** Netlify
